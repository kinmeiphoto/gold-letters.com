# Gold Letters 日本語LP 構成書（日本市場向け）

デジタル箔押し機「Gold Letters」の日本語ランディングページ構成。
B2B（製本・印刷・革製品・ノベルティ・パッケージ業界）をメインターゲットに設計。

## ターゲットと方針
- **主読者**：製本・印刷会社、革製品/文具ブランド、ノベルティ・パッケージ事業の決裁者／現場責任者
- **日本市場の重視点**：信頼性・実績・品質・サポート体制・導入のしやすさ・問い合わせ／見積もり導線
- **訴求の核**：①失敗しないライブカメラ位置決め ②活字組み不要の全自動 ③1個から作れる小ロット対応
- **デザイン参照**：`oki.com`（クリーンな日本企業サイト／コーポレートレッド `#e60012`、余白の効いたグリッド、赤アクセントバー、矢印付きボタン）

## コンバージョン設計
- **主要CTA**：「無料お見積もり・デモ依頼」をヘッダー固定＋ヒーロー＋特長内＋最終セクションに反復配置
- 価格は非公開のため、**問い合わせ／見積もり**を最終ゴールに設定
- フォームは日本のB2B慣習に合わせ「会社名・ご担当者名」を必須化

## 実装
- `index.html` … LP本体（セマンティックHTML）
- `assets/css/style.css` … OKI風スタイル（レッド `#e60012`＋ゴールド `#b8893d`、Noto Sans JP、レスポンシブ）
- `assets/js/main.js` … モバイルメニュー、スクロールアニメ、FAQアコーディオン、フォーム制御、トップへ戻る
- 画像はプレースホルダー。実機写真・加工サンプルに差し替え可能（`assets/img/`）
